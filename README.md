# 👨‍🏫 Python & Pandas for Engineering: Teaching Materials

Welcome to my academic repository! I am a 5th-semester Mechanical Engineering student at ESPOL (Ecuador) bridging the gap between mechanical design and software automation.

This repository contains the structured Python and Pandas curricula I developed and utilized during my tenure as a **Teaching Assistant for Programming Fundamentals**. 

### 🎯 The Objective
My role involves managing and mentoring groups of 15-20 engineering students per session. The objective of these notebooks is to teach complex programming logic and data analysis incrementally, moving from basic data structures to advanced engineering data manipulation using Pandas.

### 🗂️ Curriculum Structure (Jupyter Notebooks)
The files in this repository are structured chronologically to reflect the teaching methodology applied during the semester:

* **Session 1-3:** Data Types, Randomization, and Logic Structures (If/Else, For Loops).
* **Session 4-6:** Advanced Looping Mechanisms (While Loops) and Data Dictionaries.
* **Session 7-9:** Introduction to Arrays and Data Processing (NumPy).
* **Session 10-12:** Advanced Data Analysis for Engineering (Pandas DataFrames, Series, and Data Manipulation).

### 🛠️ Tech Stack
* **Language:** Python 3
* **Libraries:** Pandas, NumPy
* **Environment:** Google Colab / Jupyter Notebooks

### 💡 Why this matters
Teaching this material has significantly solidified my ability to explain technical concepts clearly and has honed my skills in writing clean, logical, and automated code—skills I am actively applying to automate thermodynamic calculations in Computational Fluid Dynamics (CFD).
